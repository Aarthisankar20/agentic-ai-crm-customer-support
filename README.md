# 🤖 Agentic AI CRM & Customer Support Platform

An intelligent CRM and customer support platform built using
Agentic AI, RAG, Gemini AI, SQLite and Streamlit.

## 🚀 Features

- 📊 Real-time CRM Analytics Dashboard
- 👥 Customer Management
- 🎫 Support Ticket Management
- 🚨 Critical Alert Center
- 📈 Advanced KPI Analytics
- 😊 Customer Sentiment Analysis
- ⚠️ Customer Urgency Detection
- 🤖 AI-Powered CRM Assistant
- 📚 RAG Knowledge Base
- 🧠 Multi-Agent Architecture

## 🏗️ Architecture

User
↓
Streamlit Dashboard
↓
Supervisor Agent
↓
CRM Agent + RAG Agent + Analytics Agent
↓
SQLite Database + Knowledge Base
↓
Gemini AI
↓
AI Response

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Google Gemini
- RAG
- Agentic AI

## 📊 Dataset

The project uses customer support conversation data to analyze:

- Customer interactions
- Support tickets
- Issue types
- Customer sentiment
- Urgency
- Industries
- Support channels

## 🎯 Project Objective

The objective of this project is to build an intelligent customer
support platform that combines CRM analytics, Retrieval-Augmented
Generation (RAG), and Agentic AI to help organizations analyze
customer problems and provide intelligent support.
